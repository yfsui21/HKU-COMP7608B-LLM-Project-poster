# Human check before submission

Status: **not completed**. No human rating is claimed by this file.

The course requires a human check when using LLM judging. A team member should inspect
source passages and exported posters, record their own judgements, and state the scope
of that check. Assistant inspection and the native model reviewer do not satisfy this.

For this curated showcase, compare the source PDF with `poster.pdf`:

- Page 5: the method diagram and its three components.
- Page 6, Table 1: the main IO2CodeBench result (58.63).
- Page 7, Table 3: full model 58.63, without EF 54.61, without TPP 53.80, without CE 51.33.
- Page 8: sampling comparison and active-exploration conditions. The source prose's
  test-time scaling average differs from the plotted average; do not conflate these.
- Read the PNG at full size and check authors, headings, figure captions, chart labels,
  protected text, and whether the method diagram is easier to read after editing.

Record reviewer name, date, files inspected, items checked, disagreements and any
corrections in a separate signed note. Checking this showcase alone does not validate
the 90-case batch. For batch checking use the frozen checklist and per-case source
quotes under `evaluation/proposal-ai-study/final/`, and report the checked sample size.
